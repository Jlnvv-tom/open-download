网页里的图片和视频，
一键批量打包带走

Open Download 在浏览器后台全局监听网络请求，自动识别网页加载的图片与视频资源。 打开弹窗即可按类型、格式、大小、尺寸筛选，预览后打包成一个 ZIP 保存到本地。

立即安装 查看源码
  • 数据仅存本地，不上传任何服务器
  • 零依赖原生实现，离线可用
  • ZIP 打包在后台完成，关闭弹窗不中断

功能特性

从捕获到落盘，一条完整的批量下载流水线

全局监听

基于 webRequest.onCompleted 的观察式监听，覆盖所有网站的网络请求，自动识别图片与视频资源。

多维筛选

媒体类型、扩展名、文件大小、图片宽高、域名排除、关键词搜索，层层过滤，快速定位目标资源。

双视图预览

信息密集的列表视图与沉浸式卡片网格自由切换，视频支持内嵌预览，选择状态跨视图保留。

ZIP 批量下载

选中或全部资源在后台 offscreen 文档中串行抓取、打包为单个 ZIP，进度实时显示，关闭弹窗不中断。

灵活设置

保存目录、命名策略（原名/域名/序号）、并发数、自动下载、URL 去重等配置，均可在设置页调整。

隐私优先

所有捕获记录仅保存在浏览器本地的 chrome.storage.local，不采集、不上传、无任何统计埋点。

工作原理

三条数据通道汇聚到本地存储，弹窗实时呈现

网络请求

Service Worker 监听 onCompleted，按 MIME / 资源类型 / 扩展名三级识别媒体

→

页面元素

Content Script 收集 <img> 的真实宽高与 alt，回填到捕获记录

→

本地存储

去重、过滤后写入 chrome.storage.local（上限 5000 条）

→

弹窗 & 下载

Popup 筛选预览，offscreen 打包 ZIP 交给 Downloads API 保存

安装使用

两种方式，任选其一

方式一：开发者模式加载

  1. 克隆仓库并安装依赖：npm install
  2. 构建产物：npm run build，生成 dist/ 目录
  3. 打开 chrome://extensions，开启右上角「开发者模式」
  4. 点击「加载已解压的扩展程序」，选择 dist/ 目录

修改源码后重新 npm run build，并在扩展卡片上点击刷新即可生效。

方式二：下载 Release 安装包

  1. 前往 GitHub Releases 页面
  2. 下载 open-download-<version>.zip
  3. 解压到任意目录
  4. 同样通过「加载已解压的扩展程序」选择解压后的目录

安装后点击工具栏图标开启监听，然后正常浏览网页即可开始捕获。

常见问题

会捕获到我不想要的图标、雪碧图吗？

可以在设置中开启大小过滤与「最小宽高」筛选（弹窗筛选面板内），或在 Options 中排除常见静态资源域名；列表中不需要的条目也可以单独移除。

ZIP 打包过程中可以关掉弹窗吗？

可以。v1.2.0 起打包任务在后台 offscreen document 中执行，关闭弹窗不会中断；重新打开弹窗后可看到最新的下载状态。

m3u8 / HLS 视频会下载成完整视频吗？

不会。扩展只捕获 m3u8 清单文件本身，不做分片下载与合并。

捕获记录会上传或同步吗？

不会。所有数据只写入本地 chrome.storage.local，扩展没有远程服务器，也没有任何遥测。

为什么需要「读取网站数据」权限？

监听网络请求需要 webRequest 与 <all_urls> 主机权限；扩展只读取请求的 URL、响应头（类型与大小），不读取页面内容，也不修改任何请求。
