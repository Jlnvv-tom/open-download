Batch Download Images and Videos: Guides

Open Download captures the images and videos a page actually loads, lets you filter and preview them, and saves the result either as a ZIP or as individual downloads. The step-by-step guides below cover the three situations people run into most often: galleries that only load images as you scroll, batches that grow into hundreds of megabytes, and the same photo appearing at several resolutions.

The detailed guides are currently available in Chinese. Full English guides are planned; until then, the written steps below the links summarise the same workflows.

The workflow behind all three guides

  1. Click the toolbar icon and make sure the switch at the top reads "Listening".
  2. Browse the page normally, or use scroll capture on a long list so the page loads its own images.
  3. Narrow the list in the filter panel: file size, minimum dimensions, source (network / page), extensions, keywords.
  4. Select what you need and hit Download selected, or Download all to let the extension choose ZIP or individual downloads.

Everything is stored in your browser's local chrome.storage.local. There is no server, no account, and no telemetry — see the privacy policy (in Chinese) for the full statement, and the Chrome downloads API documentation for the browser capability used to save files.
