批量下载网页图片：长列表页一次抓全

信息流、图库、电商列表这类长页面，往往要滚动很多屏才看得到底，而图片也正是在滚动过程中才被逐个插入页面。 结果就是：明明页面上有几百张图，抓下来的却只有开头一屏。这篇教程给出批量下载网页图片的完整做法， 核心是先用滚动抓取让页面自己把图都加载出来，再用筛选把图标、骨架屏、占位图清掉，最后预览并整批下载。

为什么长列表页总是抓不全

两个原因叠加在一起。一是懒加载：长列表页为了首屏速度，通常只为可视区域附近的图片创建 img 元素，其余位置留空，等滚动到附近再补上（这种做法的官方说明见 MDN 的 Lazy loading 词条）。 二是图片地址被脚本改写：有些站点先把占位图放进 src，再用脚本把真实地址填进去， 因此就算你手动保存网页，拿到的也可能只是一批灰色方块。

所以「抓全」的前提不是更用力地解析源码，而是让页面像人一样滚动一遍， 把该加载的资源都真实加载出来。图片一旦被加载，扩展就能从两条通道同时记录它。

第一步：让页面把图片都加载出来

打开目标页面，点击工具栏上的扩展图标，确认弹窗顶部的开关处于「监听中」，然后：

  1. 点击弹窗右上角的「滚动抓取」按钮（向下箭头图标）。
  2. 扩展会自动把页面从顶部滚动到底部，滚动过程中新增的图片会实时进入列表；按钮处于激活状态时再次点击即可停止。
  3. 等页面到底后回到弹窗，观察列表条数是否已经稳定不再增长。

滚动抓取不会跳过站点自己的「加载更多」按钮，但它会把已经渲染出的内容都滚一遍。 如果你希望更彻底，可以先手动滚到底、点几次「加载更多」，再回来查看列表——捕获是持续进行的， 不需要提前打开弹窗。

第二步：把图标、占位图筛掉

长列表页滚一遍之后，列表里往往会混进站标、评分星、社交图标、骨架屏占位图。比起逐条删， 更省事的做法是用筛选面板一次性收窄（点弹窗里的漏斗图标展开）：

  • 最小大小：填 10（KB）就能过滤掉绝大多数图标。
  • 最小尺寸：填宽度 400 以上，可以同时挡掉图标与低分辨率缩略图。
  • 扩展名：只想要无损图时填 jpg,png 之类；不填表示不限。
  • 来源：切到「网络」通常能拿到列表页里预加载的大图原图；切到「页面」则只看当前页面元素实际引用的地址。
  • 搜索框：按文件名或域名关键词过滤，适合只挑某个 CDN 的图。

筛选只影响列表的显示与「全选」的范围，不会删除已捕获的记录：把条件改回去，条目就会重新出现。 列表顶部会实时显示「匹配」条数，配合这个数字就能判断筛选条件是否合适。

第三步：预览、勾选、批量下载

  1. 点弹窗里的卡片视图按钮，可以用缩略图网格快速扫一遍结果；单张图点击后进入大图预览，支持左右切换。
  2. 不需要的条目可以单条移除，或者直接勾选你真正需要的那几十张。
  3. 点「下载选中」按当前勾选下载；点「全部下载」则按当前筛选结果整体下载。
  4. 扩展会自动决定传输方式：体积正常的批量走 ZIP 打包（在后台完成，关掉弹窗也不中断）， 单文件超过 50MB 或整包预估超过 500MB 时自动改为逐条直接下载，避免大包卡住。

下载过程中可以在弹窗底部看到进度与每条的状态；下载的文件默认存放在「下载」目录下的 OpenDownload 子目录，目录名与并发数可以在 Options 页里改。

还是抓不全？按这几条排查

  • 列表里完全没有新条目：确认顶部开关是「监听中」，并检查当前站点是否被单独暂停（弹窗里的站点行会显示「已暂停」，点「恢复跟随」即可）。
  • 只有前几张，后面都没有：页面很可能需要在可视区域内停留才会加载下一批，重新执行一次滚动抓取，或手动慢速滚动一遍。
  • 拿到的是很小的图：站点可能对同一张图提供了缩略图与原图两个地址。试试把来源切到「网络」，或在卡片视图里比较尺寸后只留大的那条；相关做法见挑选最清晰版本。
  • 图片存在但下载失败：需要登录态的图可能因为跨域限制无法打包，可在 Options 里开启「打包时携带 Cookie」后重试。
  • 数量很多、担心占空间：捕获记录上限为 5000 条，超出后自动保留最新的部分，弹窗里也会有容量提示。
