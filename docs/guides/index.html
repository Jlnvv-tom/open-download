网页图片与视频批量下载教程

批量下载网页图片这件事，难点从来不在「保存」，而在「把该保存的都找出来、把不该保存的筛掉」。 现代网页的图片大多由脚本在滚动过程中动态插入，只查看源码往往只能看到一小部分；视频则通常体积很大， 混在压缩包里下载既慢又容易失败。下面三篇教程各针对一个最常见的具体问题，给出可以直接照着做的操作步骤， 每一步对应的都是扩展里已经存在的功能，不涉及任何需要绕过的操作。

大文件为什么会在打包时报错或卡住，以及 50MB / 500MB 两个阈值如何自动改走逐条直下。

三篇教程共用的四步流程

无论具体问题是什么，落地的动作都是同一套：捕获 → 筛选 → 预览 → 下载。 捕获由扩展在后台完成（网络请求观察 + 页面元素扫描两条通道，按 URL 自动去重）；筛选在弹窗的筛选面板里做， 支持媒体类型、扩展名、文件大小、最小宽高、来源（网络 / 页面）与关键词搜索；预览可以用列表或卡片视图； 下载既可以只下选中的几条，也可以整批打包。

  1. 点击工具栏图标打开弹窗，确认顶部开关处于「监听中」。
  2. 正常浏览页面，或对长列表页启用滚动抓取，捕获到的条目会实时出现在列表里。
  3. 在筛选面板里收窄范围，例如只保留宽度大于 800 的图片、只看来源为页面元素的条目。
  4. 勾选需要的条目后点「下载选中」；要整批带走就用「全部下载」，扩展会自动决定打包还是逐条直下。

所有捕获记录只写入浏览器本地的 chrome.storage.local，扩展没有服务器，也不会上传任何数据。 权限用途的完整说明见隐私政策；扩展实际使用的下载能力可对照 Chrome 官方 downloads API 文档。

从哪一篇开始

  • 图片抓不全、列表里混进大量图标 → 先看长列表页抓图教程。
  • 下载几百 MB 视频时失败或长时间卡住 → 先看大文件批量下载教程。
  • 同一张图有多个版本、不知道该留哪个 → 先看挑选最清晰版本教程。
