隐私政策

最后更新：2026-09-21 · 适用于 Open Download 扩展 v1.5.0 及以后版本

一句话总结

Open Download 不收集、不上传、不共享任何用户数据。所有捕获记录与设置只保存在你自己的浏览器里。

1. 我们处理哪些数据

扩展在运行过程中会在你的设备本地生成以下数据：

  • 被捕获媒体的 URL、文件名、域名、扩展名、MIME 类型、文件大小、宽高、时长、封面地址；
  • 捕获发生时的来源页面地址与标题，用于「按页面分组」展示；
  • 捕获时间与下载状态；
  • 你的扩展设置（开关、过滤条件、保存目录、命名策略、站点级开关等）。

上述数据全部存放在 chrome.storage.local，仅存在于本机浏览器配置中。卸载扩展或清理浏览器数据即被删除。

2. 我们不做哪些事

  • 不向任何服务器发送数据，扩展没有自建后端，也没有第三方统计、埋点或广告 SDK；
  • 不含任何远程加载的代码或资源，扩展页面完全离线可用；
  • 不使用 Cookie 或本地存储做用户标识与追踪；
  • 不读取、不修改你的网页内容；不修改、不阻塞、不注入任何网络请求，仅观察已完成的请求；
  • 不绕过登录、付费墙或任何访问控制，也不解密 DRM 保护内容。

3. 网络访问说明

扩展只在两种情况下发起网络请求，且请求目标都由你自己指定：

  • 单条下载 / ZIP 打包：从媒体资源的原始地址抓取文件内容，交给 Chrome 下载管理器保存到本地「下载」文件夹。
  • 可选的「打包时携带 Cookie」：该选项默认关闭。开启后，打包请求会携带目标站点的 Cookie，用于你已登录、需要凭据才能访问的资源。此开关只影响打包请求，不会上传或外传任何 Cookie 内容。

4. 权限用途

扩展申请的每项权限都只服务于上述功能，与代码实现严格一致：

权限用途边界
webRequest 读取已完成请求的 URL 与响应头，识别媒体资源 仅观察（onCompleted），不拦截、不阻塞、不修改请求
downloads 触发单条下载与 ZIP 下载 只在用户点击下载时调用
storage 保存捕获记录与设置 仅使用 chrome.storage.local，不使用云端同步
offscreen 在后台文档中打包 ZIP，关闭弹窗不中断 仅在用户主动打包时按需创建，下载结束即关闭
contextMenus 提供「开启/关闭监听」「暂停此站点捕获」等右键入口 仅添加菜单项，不读取页面内容
<all_urls> 在所有网站上生效所需的宿主权限 仅用于本地识别与抓取，不向任何服务器发送网页信息

5. 数据共享与第三方

不存在。扩展没有任何数据接收方，没有第三方服务商，也不会因商业目的出售或转让任何数据。

6. 未成年人

扩展不面向未成年人设计，也不会有意收集未成年人的任何信息。

7. 政策变更

如隐私政策发生实质性变化，会在本页面更新「最后更新」日期，并在扩展的 Release 说明中注明。

8. 联系方式

任何隐私相关疑问，可通过 GitHub Issues 联系维护者。

Privacy Policy (English)

Last updated: 2026-09-21 · Applies to Open Download v1.5.0 and later

Summary

Open Download does not collect, upload, or share any user data. Everything it captures stays inside your own browser.

1. What is processed

The extension stores the following data locally on your device: captured media metadata (URL, filename, domain, extension, MIME type, byte size, dimensions, duration, poster URL); the source page URL and title used for grouping; capture time and download status; and your extension settings.

All of it lives in chrome.storage.local. Uninstalling the extension or clearing browser data removes it.

2. What is never done

  • No data is sent to any server. There is no backend, no analytics, no telemetry, and no advertising SDK.
  • No remote code or remote assets are loaded; extension pages work fully offline.
  • No cookies or local storage are used to identify or track you.
  • Page content is never read or modified, and network requests are never blocked, altered, or injected. Requests are only observed after completion.
  • Login walls, paywalls, and DRM-protected content are never bypassed or decrypted.

3. Network access

Outbound requests happen only when you ask for them, and always target the media URL you selected: single-item downloads and ZIP packing fetch the resource so Chrome's download manager can save it locally.

The optional "send cookies when packing" setting is off by default. When enabled, packing requests include the target site's cookies so that login-protected media can be fetched. It affects packing requests only and never transmits cookies anywhere else.

4. Permissions

  • webRequest — read completed requests (URL and response headers) to detect media. Observation only: no blocking, no modification.
  • downloads — save files you explicitly choose to download.
  • storage — keep captured records and settings in chrome.storage.local; no cloud sync.
  • offscreen — build ZIP archives in a background document so closing the popup does not interrupt packing. Created on demand and closed afterwards.
  • contextMenus — provide right-click entries for toggling capture globally or per site.
  • <all_urls> — host permission required to work on any website; used locally only.

5. Sharing and third parties

None. There are no recipients, no service providers, and no sale or transfer of data for commercial purposes.

6. Changes

Material changes to this policy update the "last updated" date above and are noted in the extension release notes.

7. Contact

For privacy questions, open an issue on GitHub Issues.
